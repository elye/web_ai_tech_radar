# Perplexity LLM

## Overview
Perplexity AI's large language models are designed for real-time information retrieval and analysis, combining conversational AI with live web search capabilities. These models excel at providing up-to-date, citation-backed responses by searching and synthesizing information from the web in real-time.

## Key Benefits
- Real-time web search integration for current information
- Automatic citation and source attribution
- Multiple model options (Perplexity, Claude, GPT-4, etc.)
- Fast response times with accurate, up-to-date data
- Focus mode for specialized domains (Academic, Writing, Math, etc.)
- API access for integration into applications

## When to Use
- Research tasks requiring current information
- Fact-checking and verification workflows
- Educational applications needing cited sources
- News and current events analysis
- Academic research with source attribution
- Applications requiring real-time data synthesis

## Considerations
- Dependent on web search quality and availability
- May have varying accuracy based on source reliability
- Rate limits apply to free tier usage
- Subscription required for advanced features and higher usage
- Limited customization compared to base models
- Results quality depends on search result relevance

## Cost
**Freemium** - Free tier with limited queries per day. Perplexity Pro starts at $20/month for unlimited queries, advanced AI models, and API access.

## Recommended Tools
- Perplexity API for developers
- Browser extensions for quick access
- Integration with note-taking apps
- Research and writing workflows
- Academic citation managers
