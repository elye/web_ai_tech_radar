# Perplexity Sonar Pro

## Overview
Sonar Pro is Perplexity's advanced in-house model, built on Llama 3.1 70B. It is optimized for search, reasoning, and factuality, designed to integrate seamlessly with Perplexity's real-time search engine.

## Key Benefits
- **Enhanced Factuality:** Purpose-built for high accuracy and reduced hallucinations.
- **Deep Research:** Delivers deeper content understanding and 2x more search results.
- **Reasoning:** Capable of handling complex, multi-step queries with a large context window.
- **Citations:** Provides double the number of citations for transparency.
- **Real-time:** Powered by live internet access.

## When to Use
- Deep research and fact-checking.
- Complex queries requiring up-to-date information.
- Tasks where source verification and citations are critical.

## Cost
**Paid** - Available with Perplexity Pro subscription and API.
