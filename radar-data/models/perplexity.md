# Perplexity

## Overview
Perplexity is an AI-powered search and reasoning engine that combines large language models with real-time web search capabilities. Unlike traditional search engines, it provides synthesized answers with citations, making it useful for research, fact-checking, and learning about current topics.

## Key Benefits
- Real-time web search integration for current information
- Transparent citations showing sources for claims
- Multiple answer modes (Copilot for detailed research, Concise for quick answers)
- Supports conversation and context retention
- Free tier with generous usage limits
- API access for developers
- Strong reasoning capabilities for complex queries

## When to Use
- Research and information gathering on current topics
- Fact-checking and verification with source attribution
- Quick answers with reliable sources
- When you need citations for claimed information
- Complex multi-step reasoning and analysis
- Learning about new topics with structured explanations

## Considerations
- Requires internet connection for web search functionality
- API costs may apply for high-volume usage
- Newer model compared to established alternatives like GPT-4
- Some users report occasional hallucinations despite web search
- Free tier has request limits
- Performance may vary based on query complexity

## Cost
**Freemium** - Free tier includes unlimited basic searches with limited advanced features. Pro subscription ($20/month) includes priority access, priority search mode, and higher API limits.

## Recommended Tools
- OpenAI API - For comparison and integration with other LLM workflows
- LangChain - For building applications that leverage Perplexity's search capabilities
- Anthropic API - Alternative LLM platform for comparison
- Groq - For high-speed inference alternatives
