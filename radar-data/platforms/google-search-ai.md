# Google Search AI Mode

## Overview
Google Search AI Mode is a new paradigm for search that integrates Gemini 3 to offer dynamic, agentic capabilities. It includes features like "Canvas" for planning, file uploads for analysis, and generative UI for interactive simulations.

## Key Benefits
- **Canvas:** A dedicated workspace for organizing search results and building plans.
- **Generative UI:** Creates interactive tools and simulations directly in search results.
- **Deep Search:** Breaks down complex queries into multi-step research tasks.
- **Multimodal:** Supports video input and file uploads for context-aware searching.

## When to Use
- Complex research topics requiring synthesis of multiple sources.
- Planning tasks (travel, study, projects).
- Interactive learning and problem solving.

## Cost
**Free** - Integrated into Google Search.
