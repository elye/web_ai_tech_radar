# AntiGravity by Google

## Overview
AntiGravity is Google's new "agent-first" IDE, launched in preview in November 2025. It is designed to let developers build software using autonomous AI agents that can plan, code, test, and debug, rather than just offering inline suggestions.

## Key Benefits
- **Agent-First Paradigm:** Prioritizes autonomous agents for complex tasks.
- **Dual-View Workflow:** "Editor View" for coding and "Mission Control" for managing agents.
- **Multi-Agent System:** Orchestrates multiple agents working in parallel on different tasks.
- **Cross-Surface Control:** Agents operate across editor, terminal, and built-in browser.
- **Gemini 3 Pro:** Deeply integrated with Google's latest reasoning model.
- **Artifacts:** Generates verifiable deliverables like plans and recordings.

## When to Use
- Building complex features requiring planning and multi-step execution.
- Managing multiple work streams simultaneously.
- Projects benefiting from deep Google ecosystem integration.
- Developers looking for a shift from "typing" to "managing" code.
