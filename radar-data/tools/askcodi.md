# AskCodi

## Overview
AskCodi is a comprehensive AI coding assistant designed to speed up development. It offers a suite of tools for code generation, unit test creation, documentation, and code explanation, integrated into popular IDEs.

## Key Benefits
- **Tool Suite:** Dedicated tools for specific tasks (regex, tests, sql).
- **IDE Extensions:** Available for VS Code, JetBrains, and Sublime.
- **Chat:** Conversational coding assistance.
- **Multi-Language:** Supports a wide range of programming languages.

## When to Use
- Developers needing specific helper tools (e.g., generating complex regex).
- Quick code explanations and documentation generation.
- Students and junior developers learning new concepts.

## Cost
**Freemium** - Free basic tier; paid premium features.
