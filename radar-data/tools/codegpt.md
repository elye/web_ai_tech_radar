# CodeGPT

## Overview
CodeGPT is a powerful extension that allows developers to use various LLMs (OpenAI, Anthropic, Llama, etc.) directly within their IDE. It features specialized agents for tasks like code review, refactoring, and onboarding.

## Key Benefits
- **Model Agnostic:** Connect to OpenAI, Anthropic, Ollama, and more.
- **Specialized Agents:** Pre-built agents for specific dev tasks.
- **Context Management:** Upload documents and codebase context.
- **Open Source:** Community-driven extension.

## When to Use
- Developers who want flexibility in choosing their underlying LLM.
- Teams needing specialized agents for code review and refactoring.
- Privacy-conscious users running local models via Ollama.

## Cost
**Freemium** - Extension is free; API costs depend on the provider.
