# Codeium

## Overview
Codeium is a high-performance, free AI coding assistant that rivals GitHub Copilot. It supports over 70 languages and offers ultra-fast autocomplete, chat, and search capabilities, with a strong commitment to individual user privacy.

## Key Benefits
- **Free for Individuals:** Powerful features at no cost.
- **Speed:** Ultra-low latency suggestions.
- **Wide Support:** Works in almost any IDE (VS Code, JetBrains, Vim, etc.).
- **Privacy:** Does not train on user code (for enterprise/teams).

## When to Use
- Developers looking for a free, high-quality alternative to Copilot.
- Users of niche IDEs (Vim, Emacs) needing AI support.
- Teams requiring strict privacy controls (Enterprise plan).

## Cost
**Free** for individuals; paid for teams and enterprise.
