# Cody

## Overview
Cody by Sourcegraph is an AI coding assistant designed for enterprise scale. It leverages Sourcegraph's powerful code search graph to understand your entire codebase, providing highly context-aware answers and code generation.

## Key Benefits
- **Deep Context:** Understands massive codebases via knowledge graph.
- **Enterprise Grade:** Built for security and scale.
- **Model Agnostic:** Choose between Claude, GPT-4, and others.
- **Code Search:** Integrated with Sourcegraph's search capabilities.

## When to Use
- Large enterprises with massive, complex codebases.
- Teams needing precise answers based on project-wide context.
- Organizations requiring strict data privacy and model choice.

## Cost
**Freemium** - Free tier available; paid enterprise plans.
