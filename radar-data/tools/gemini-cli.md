# Gemini CLI

## Overview
Gemini CLI is an open-source command-line tool that brings Google's Gemini models to the terminal. It acts as an AI agent for coding assistance, debugging, and general task management, with a generous free tier.

## Key Benefits
- **Open Source:** Fully customizable and extensible.
- **1M Token Context:** Uses Gemini 2.5 Pro for deep project understanding.
- **Google Search:** Integrated real-time information retrieval.
- **Free Tier:** Generous access to powerful models.
- **Native Windows Support:** Runs without WSL.

## When to Use
- Quick debugging and code explanations in the terminal.
- Developers looking for a free, high-context CLI assistant.
- Projects requiring Google Search integration for up-to-date info.

## Cost
**Free** - Open source with generous free usage tier.
