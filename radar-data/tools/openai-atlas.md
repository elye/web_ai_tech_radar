# OpenAI Atlas

## Overview
OpenAI Atlas is an AI-first web browser that integrates ChatGPT directly into the browsing experience. It features an "Agent Mode" that can autonomously perform multi-step web tasks and "Browser Memories" to retain context across sessions.

## Key Benefits
- **Agent Mode:** Autonomously navigates websites to complete complex tasks like booking travel.
- **Deep Integration:** ChatGPT is embedded in every page for summarization and analysis.
- **Browser Memories:** Remembers context and preferences across browsing sessions.
- **Chromium Based:** Compatible with existing web standards and extensions.

## When to Use
- Research-heavy browsing sessions.
- Automating repetitive web-based tasks.
- Users deeply invested in the OpenAI ecosystem.

## Cost
**Freemium** - Free basic use; Agent Mode requires Plus/Pro subscription.
