# Pear AI

## Overview
Pear AI is an open-source AI code editor (fork of VS Code) that focuses on clarity, reliability, and clean code. It aims to reduce technical debt by helping developers refactor and modernize their codebases with AI guidance.

## Key Benefits
- **Open Source:** Transparent and community-driven.
- **Clean Code Focus:** Prioritizes maintainability and best practices.
- **Refactoring:** Specialized in modernizing legacy code.
- **VS Code Compatible:** Familiar interface and extension support.

## When to Use
- Projects requiring significant refactoring or modernization.
- Teams prioritizing code quality and maintainability.
- Developers who prefer open-source tools.

## Cost
**Free** - Open source model.
