# Visual Studio Code

## Overview
Visual Studio Code (VS Code) continues to be the dominant code editor, with significant AI updates in 2025. It now features a built-in AI coding companion, deeper agent integration, and is moving towards open-sourcing its core AI components.

## Key Features
- **Built-in AI:** Native AI assistant powered by Copilot and IntelliCode.
- **Agent HQ:** Centralized management for AI agents and workflows.
- **Model Support:** Access to GPT-5, Claude Sonnet 4.5, and others via extensions.
- **MCP Support:** Integration with Model Context Protocol for external tools.
- **Open Source Core:** Moving towards a fully open-source AI editor foundation.

## When to Use
- General purpose software development.
- Developers who prefer a highly customizable and extensible editor.
- Teams deeply integrated into the Microsoft/GitHub ecosystem.

## Cost
**Free** - The editor is free; Copilot and some AI features require subscriptions.

## Status
**Ring: ADOPT** - The industry standard editor, now evolving with powerful native AI capabilities.
