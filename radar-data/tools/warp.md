# Warp

## Overview
Warp is a modern, Rust-based terminal that reimagines the command line interface. It features built-in AI command search, collaborative workflows, and a modern UI that treats terminal output as blocks.

## Key Benefits
- **AI Command Search:** Natural language to shell command translation.
- **Warp Drive:** Share commands and workflows with your team.
- **Modern UI:** Mouse support, blocks, and IDE-like editing.
- **Speed:** High-performance rendering via Rust.

## When to Use
- Daily terminal usage for developers and DevOps.
- Teams wanting to share CLI knowledge and scripts.
- Users seeking a more modern, user-friendly terminal experience.

## Cost
**Freemium** - Free for individuals; paid for teams.
